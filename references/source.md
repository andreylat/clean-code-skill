# Source and navigation

This skill derives from **Clean Code: A Handbook of Agile Software Craftsmanship**, **Second Edition**, by **Robert C. Martin**. The title page identifies the source copy as an **early release** with unedited content (PDF p. 2). Guidance and chapter numbering therefore belong to this source copy, not an assumed first edition or a later finalized edition. The source PDF is not included in this repository.

- Length: 649 PDF pages.
- SHA-256: `c570dfc11b84d35ab8a16242292285c5256127df022334cf552a5c098b6a319e`.
- Page convention: all references use 1-based PDF page positions, including front matter. They are not printed page numbers.
- The skill contains paraphrased operational guidance and context-sensitive adaptations. It does not reproduce the book or its example listings.
- The introductory account of the four-part structure is on PDF p. 17. The book explicitly includes contrary viewpoints and later reactions to its own examples (PDF pp. 15-16).
